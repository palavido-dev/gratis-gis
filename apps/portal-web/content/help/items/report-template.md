A **report template** would be a document layout that fills PDF,
Word, or HTML from layer rows or form submissions. That item is
not built. The create picker does not offer it. A leftover row
shows a coming-soon notice and the raw data. There is no generate
button.

Paper output that does ship is a **print template**: a page layout
for the Print tool inside a web app.
