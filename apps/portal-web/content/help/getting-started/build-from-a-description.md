Open **Build** in the navigation (`/assistant`). Describe what you want in plain
language. A sentence such as "a map of park benches, a form to
report a broken one, and an app that shows both" is enough.

**Speak** uses the microphone in Chrome and other browsers that
offer speech recognition. The words land in the text box. Nothing
is created until you choose **Build it**.

GratisGIS looks at data layers you can already open. When one of
them fits the description, the new map uses that layer. Otherwise
it creates an empty layer with the fields the description implied.
It can also create a form and a viewer app in the same step.
Open any of the links it shows to keep editing.

An organization admin turns this on under **Admin → AI**. Until
a provider is saved, Build explains that and stops.
